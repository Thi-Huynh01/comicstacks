# 📚 Comic Stacks
Comic Stacks is a full-stack web application for comic book fans to discover, discuss, and review comics from a variety of publishers and genres. It combines a modern React frontend with a Django REST framework backend. Users will be able to browse comics, write reviews, create threads/discussion forums, and engage with other users. 

# ⭐ Features that will be implemented
Reviewing Comics <br>
Displaying highly rated Comics <br>
Community discussion Forums <br>
Browsing Users <br>
Adding comics to a list <br>

# 🤖 Tech Stack <br>
**Frontend:** React + Vite, React Router, Material UI <br>
**Backend:** Django, Django REST Framework <br>
**Database:** SQLite <br>
**Auth:** Django Authentication (Token-based) <br>
**Styling:** CSS + MUI (light/dark mode) <br>
